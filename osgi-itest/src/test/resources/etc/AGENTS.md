# `osgi-itest/src/test/resources/etc` — Karaf `etc/` config overrides copied into the Pax Exam container

| File | Purpose |
|---|---|
| `org.ops4j.pax.logging.cfg` | pax-logging log4j2 config for the test container. Sets `log4j2.rootLogger.level = DEBUG` with appender refs `Console`, `RollingFile`, `PaxOsgi`; console output is gated by a `ThresholdFilter` at `${karaf.log.console:-INFO}`, so DEBUG reaches `${karaf.log}/karaf.log` but not stdout unless `karaf.log.console` is lowered. Rolling appender is `RollingRandomAccessFile` with `SizeBasedTriggeringPolicy` at `16MB`, pattern `log4j2.pattern` = `%d{ISO8601} \| %-5p \| %-16t \| %-32c{1} \| %X{bundle.id} - %X{bundle.name} - %X{bundle.version} \| %m%n`. Aether/http-header/maven TRACE loggers are present but commented out — uncomment them to debug `mvn:` resolution failures. File ends with a stray `s` line. |
| `org.ops4j.pax.url.mvn.cfg` | pax-url-aether resolver config that decides where `mvn:` bundle URLs in `test-features.xml` are fetched from. Points `org.ops4j.pax.url.mvn.settings` at `${basedir}/../.maven.xml` — the reactor-local settings file, not `~/.m2/settings.xml`; deleting it breaks every artifact resolution in the container. Sets `useFallbackRepositories=false` and `certificateCheck=true`, lists `defaultRepositories` as the karaf system repo, the `kar` data repo, and the child system repo (all `@snapshots`), and `repositories` as central + apache snapshots-group + ops4j-snapshots. Socket budget: `timeout`/`socket.connectionTimeout` `5000` ms, `socket.readTimeout` `30000` ms, `connection.retryCount` `3` — a slow mirror makes the itest fail as a resolution timeout, not as an assertion failure. `localRepository` is intentionally left commented out. |
